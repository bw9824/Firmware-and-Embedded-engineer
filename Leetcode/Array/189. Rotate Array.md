# 189. Rotate Array

### Problem
Given an integer array nums, rotate the array to the right by k steps, where k is non-negative.

```
Example 1:
Input: nums = [-1,-100,3,99], k = 2
Output: [3,99,-1,-100]
Explanation: 
rotate 1 steps to the right: [99,-1,-100,3]
rotate 2 steps to the right: [3,99,-1,-100]
```

### Solution 1
```c =
void rotate(int* nums, int numsSize, int k) {
    
    k = k % numsSize;
    if (k == 0) return;

    int* temp = (int*)malloc(numsSize * sizeof(int));
    

    for (int i = 0; i < numsSize; i++) {
        temp[(i + k) % numsSize] = nums[i];
    }
    
    for (int i = 0; i < numsSize; i++) {
        nums[i] = temp[i];
    }
    
    free(temp);
}
```

### Solution 2
```c =
void rotate(int* nums, int numsSize, int k) {
    
    k = k % numsSize;
    if (k == 0) return;

    int count = 0; // Record the number of people who seat in the new seats.
    
    for(int start = 0; count < numsSize; start++){
        int current_idx = start;
        int prev_val = nums[start]; // Save the kicked out value
        
        do {
            int next_idx = (current_idx + k) % numsSize; // Find the index to place the number
            int temp = nums[next_idx]; // Save the next_idx kicked out value
            nums[next_idx] = prev_val;
            prev_val = temp;
            
            current_idx = next_idx;
            count++;
        } while (start != current_idx); //  for the case index 0 -> index 2 -> index 4 -> index 0 (break)
    }
}
```
