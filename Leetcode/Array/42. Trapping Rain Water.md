# 42. Trapping Rain Water

### Problem
Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

```
Example 1:
Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
Explanation: The above elevation map (black section) is represented by array [0,1,0,2,1,0,1,3,2,1,2,1].
In this case, 6 units of rain water (blue section) are being trapped.
```
### Note
The water trapped at any position only depends on the smaller of the two boundary maxes, so we don't need the exact value of the taller side — just knowing it's taller than the shorter side is enough.  
Using this, two pointers move inward from both ends, always advancing the side with the smaller height, since that side's trapped water is already determined by its own running max.  
We keep left_max and right_max updated as we go, adding water whenever the current bar is shorter than its side's max, until the pointers meet.

### Solution
```c
int trap(int* height, int heightSize) {
    int left = 0, right = heightSize - 1;
    int ans = 0;
    int left_max = 0, right_max = 0;

    while (left < right) {
        // The left side is shorter, so the water volume in this cell is only limited by leftMax.
        if (height[left] < height[right]) {
            if (height[left] >= left_max) {
                left_max = height[left];
            }
            else {
                ans += (left_max - height[left]);
            }
            left++;
        } 
        else {
            if (height[right] >= right_max){
                right_max = height[right];
            }
            else {
                ans += (right_max - height[right]);
            }
            right--;
        }
    }
    return ans;
}
```
