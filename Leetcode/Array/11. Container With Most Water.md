# 11. Container With Most Water

### Problem
You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.

Notice that you may not slant the container.

```
Example 1:
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7].
In this case, the max area of water (blue section) the container can contain is 49.
```
### Note
This solves "Container With Most Water" using two pointers starting at both ends.   
At each step, the water area is limited by the shorter of the two walls, so moving the taller pointer inward can never help — it only shrinks the width while the height limit stays the same or gets worse.   
So we always move the shorter side inward instead, since that's the only pointer move that could possibly find a taller wall and a larger area.

### Solution
```c
int maxArea(int* height, int heightSize) {
    int right = heightSize-1, left = 0;
    int tmp = 0, maxArea = 0;

    while (left < right) {
        if (height[left]<height[right]) {
            tmp = height[left] * (right-left);
            left++;
        }
        else{
            tmp = height[right] * (right-left);
            right--;
        }

        maxArea = ( maxArea < tmp ) ? tmp : maxArea;
    }

    return maxArea;
}
```
