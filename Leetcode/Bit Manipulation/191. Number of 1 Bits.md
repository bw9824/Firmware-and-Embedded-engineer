# 191. Number of 1 Bits

### Problem
Given a positive integer n, write a function that returns the number of set bits in its binary representation (also known as the Hamming weight).
```
Example 1:
Input: n = 11

Output: 3

Explanation:

The input binary string 1011 has a total of three set bits.
```

```

```
### Solution 1
```c =
int hammingWeight(int n) {
    
    int result=0;
    while(n>0){
        if (n&1){
            result++;
        }
        n>>=1;
    }
    return result;
}
```
Issue 1 & Fix 1
```
Coding performance: Brian Kernighan's n & (n - 1)
It can eliminate the rightmost 1 in the binary representation.
```

### Solution 2
```c =
int hammingWeight(int n) {
    
    int result = 0;
    while (n != 0){      // != 0, It can also use for negative
        n&=(n-1);
        result++;
    }
    return result;
}
```
