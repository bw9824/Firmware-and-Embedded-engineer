# 137. Single Number II

### Problem
Given an integer array nums where every element appears three times except for one, which appears exactly once. Find the single element and return it.

You must implement a solution with a linear runtime complexity and use only constant extra space.

```
Example 1:
Input: nums = [0,1,0,1,0,1,99]
Output: 99
```
### Note
```
Each bit will be a multiple of three.
```
### Solution 1
```c =
int singleNumber(int* nums, int numsSize) {
    int ones = 0, twos = 0, int threes;

    for (int i=0; i<numsSize; i++){
        twos |= (ones & nums[i]);  // Update bits that appear twice
        ones ^= nums[i];  // Update bits that appear once: Use XOR to flip them as they appear.
        threed = ones & twos;

        // Remove the bits that have accumulated up to 3 times from ones and twos (invert and then AND).
        ones &= ~threed;
        twos &= ~threed;
    }

    return ones;
}
```
