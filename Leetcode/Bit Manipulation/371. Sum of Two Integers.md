### Problem
Given two integers a and b, return the sum of the two integers without using the operators + and -.

```
Example 1:
Input: a = 1, b = 2
Output: 3
```
### Note
```

```
### Solution 1
```c =
int getSum(int a, int b) {

    while (b!=0){
        int carry = (int)((unsigned int)(a&b)<<1); // (a&b): The leftmost number could be 1, representing a negative number.
        
        a = a^b;
        b = carry;
    }
    return a;
}
```
