# 172. Factorial Trailing Zeroes

### Problem
Given an integer n, return the number of trailing zeroes in n!.

Note that n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1.

```
Example 1:
Input: n = 5
Output: 1
Explanation: 5! = 120, one trailing zero.
```
### Note
```
Cause 2*5=10, n! = 1*2*3*4*5*6*7*8....*n
There must be a 2 before any multiple of 5, so we only need to consider the number of 5.

Each time, divide n by 5 and add it to the counter.
First round: Count how many multiples of 5 there are.
Second round: Count how many multiples of 25 there are (because 25 = 5 * 5, it will contribute an extra 5).
Third round: Count how many multiples of 125 there are...
```
### Solution 1
```c =
int trailingZeroes(int n) {
    int zero_cnt = 0;

    while (n>=5){
        zero_cnt += n / 5;
        n /= 5;
    }

    return zero_cnt;
}
```
