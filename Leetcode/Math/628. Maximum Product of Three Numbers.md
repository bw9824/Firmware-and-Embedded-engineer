# 628. Maximum Product of Three Numbers

### Problem
Given an integer array nums, find three numbers whose product is maximum and return the maximum product.

```
Example 1:
Input: nums = [-1,-2,-3]
Output: -6
```
### Note

There are 4 possibility
+++, --- : The top 3 by value (max1×max2×max3) automatically gives the best product
+-- The smallest two negatives (min1×min2) flip to positive, multiplying by the largest positive (max1) may beat the top-3 product
++- : As long as the array size is greater than or equal to 3, the worst case is when all three numbers are negative.

### Solution
```c
int maximumProduct(int* nums, int numsSize) {
    int max2=INT_MIN, max1=INT_MIN, max0=INT_MIN, min1=INT_MAX, min0=INT_MAX;

    for(int i = 0; i < numsSize; i++){
        int n = nums[i];

        if(n > max0){
            max2 = max1;
            max1 = max0;
            max0 = n;  // max0 is the max value
        } 
        else if(n > max1){
            max2 = max1;
            max1 = n;
        } 
        else if(n > max2){
            max2 = n;  // the third one
        }

        if(n < min0){
            min1 = min0; 
            min0 = n;  // min0 is the min value
        } 
        else if(n < min1){
            min1 = n;
        }
    }

    int product1 = max0 * max1 * max2;
    int product2 = min0 * min1 * max0;

    return (product1 > product2 ? product1 : product2);
    
}
```
