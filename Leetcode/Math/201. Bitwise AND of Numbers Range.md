# 201. Bitwise AND of Numbers Range

### Problem
Given two integers left and right that represent the range [left, right], return the bitwise AND of all numbers in this range, inclusive.

```
Example 1:
Input: left = 5, right = 7
Output: 4
```
### Note
```
Because the numbers are increasing, the digits (the ones and tens digits) will always undergo a "carry-over" process. Therefore, the middle number can be ignored.
```
### Solution 1
```c =
int rangeBitwiseAnd(int left, int right) {
    int shift = 0;
    
    while (left<right){
        left >>= 1;
        right >>= 1;
        shift++;
    }
    
    return left << shift;
}
```
