# 3. Longest Substring Without Repeating Characters

### Problem
Given a string s, find the length of the longest substring without duplicate characters.

```
Example 1:
Input: s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3. Note that "bca" and "cab" are also correct answers.
```
### Note
For each character, this algorithm keeps track of the position right after where that character last appeared. This is stored in an array, indexed by the character's ASCII value.

As the window moves forward one character at a time, the algorithm checks whether the current character has appeared before, inside the current window. If it has, the window's left edge jumps directly to just past that character's last position, instead of moving forward one step at a time. This jump is what makes the algorithm efficient, since it skips ahead in one move rather than shrinking the window gradually.

At every step, the algorithm calculates the current window's length and keeps track of the longest one seen so far.
### Solution
```c
int max(int a, int b) { return (a > b) ? a : b; }

int lengthOfLongestSubstring(char* s) {
    // For each character (by ASCII value), store "last seen index + 1".
    int charToNextIndex[256] = {0}; // unsigned char: 0 ~ 255, a total of 256 possible values.

    int maxLen = 0;
    int left = 0;      // Left edge of the current window (inclusive).
    int n = strlen(s);

    // right = right edge of the current window; moves forward one step at a time.
    for (int right = 0; right < n; right++) {

        int index = (int)s[right];  // ASCII value of current character, used as array index.

        // If this character value > 0 means "seen", jump the left edge forward to just past where it last appeared.
        if (charToNextIndex[index] > 0) {
            // Left should only ever move forward.
            left = max(left, charToNextIndex[index]);
        }

        // Update maxLen only if this window is bigger than what we've seen before.
        maxLen = max(maxLen, right - left + 1);

        // Record that this character was just seen at position `right`.
        charToNextIndex[index] = right + 1;
    }

    return maxLen;
}
```
