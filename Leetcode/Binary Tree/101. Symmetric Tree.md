101. Symmetric Tree

### Problem
Given the root of a binary tree, check whether it is a mirror of itself (i.e., symmetric around its center).

```
Example 1:
Input: root = [1,2,2,null,3,null,3]
Output: false
```
### Note

To check if two subtrees are mirrors, we compare them from the top down. First, we check the easy cases: if both are empty, they match. If only one is empty, they don't match.

If both subtrees have nodes, we check three things: the two root values must be equal, the left child of one must mirror the right child of the other, and the right child of one must mirror the left child of the other.

We repeat this process recursively, going deeper into the tree each time, until we reach the empty nodes at the bottom. If every pair matches all the way down, the whole tree is symmetric.

### Solution
```c
/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     struct TreeNode *left;
 *     struct TreeNode *right;
 * };
 */

bool isMirror(struct TreeNode* t1, struct TreeNode* t2) {
    // Base case 1: both empty -> mirrored
    if (t1 == NULL && t2 == NULL) return true;
    // Base case 2: only one is empty -> not mirrored
    if (t1 == NULL || t2 == NULL) return false;

    // Values must match, and subtrees must mirror in crossed order
    return (t1->val == t2->val)
        && isMirror(t1->left, t2->right)
        && isMirror(t1->right, t2->left);
}

bool isSymmetric(struct TreeNode* root) {
    if (root == NULL) return true;  // an empty tree is symmetric
    return isMirror(root->left, root->right);
}
```
