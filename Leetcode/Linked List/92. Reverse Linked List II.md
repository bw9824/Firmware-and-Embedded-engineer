# 92. Reverse Linked List II

### Problem
Given the head of a singly linked list and two integers left and right where left <= right, reverse the nodes of the list from position left to position right, and return the reversed list.

```
Example 1:
Input: head = [1,2,3,4,5], left = 2, right = 4
Output: [1,4,3,2,5]
```

### Solution 1
```c =
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* reverseBetween(struct ListNode* head, int left, int right) {
    
    if (head == NULL || left == right) return head;

    // For the case of left = 1
    struct ListNode dummy;
    struct ListNode *pre = &dummy;
    pre->next = head;

    // Step 1: Move pre to the node before left
    for (int i = 1; i < left; i++) {
        pre = pre->next;
    }

    struct ListNode *cur = pre->next; // the first node need to move
    struct ListNode *next = NULL;

    for (int i = 0; i < right - left; i++) {
        next = cur->next;      // Store next node address
        cur->next = next->next;// cur connect to the second address after it.
        next->next = pre->next;// the next node connects to the cur node
        pre->next = next;      // the node before left connects the next node
    }

    return dummy.next;
}
```
