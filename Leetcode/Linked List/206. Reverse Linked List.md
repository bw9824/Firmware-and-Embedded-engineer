# 206. Reverse Linked List

### Problem
Given the head of a singly linked list, reverse the list, and return the reversed list.

```
Example 1:
Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]
```
### Note 1
```
Node A：Address 0x100, val 10, pointer to 0x200
Node B：Address 0x200, val 20, pointer to 0x300
Node C：Address 0x300, val 30, pointer to NULL
```

|         | pre/pre->next       | cur/cur->next        | next/next->next          |
| ------- | ------------------- | -------------------- | ------------------------ |
| Initial | NULL                | 0x100 (Node A)/0x200 | NULL                     |
| Loop1   | 0x100/NULL          | 0x200/0x300          | 0x200 (Node B)/0x300     |
| Loop2   | 0x200/0x100         | 0x300/NULL           | 0x300 (Node C)/NULL      |
| Loop3   | 0x300/0x200         | NULL                 | NULL                     |

### Solution 1
```c =
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* reverseList(struct ListNode* head) {
    struct ListNode *pre = NULL;
    struct ListNode *cur = head;
    struct ListNode *next = NULL;

    while (cur != NULL) {
        next = cur->next; // Update the next node addresses
        cur->next = pre; // Reverse pointer address
        pre = cur; // Update pre for the next node to point to
        cur = next; // For the next node
    }

    return pre;
}
```
### Note 2
**Recursive Solution**
```
Node A：Address 0x100, val 10, pointer to 0x200
Node B：Address 0x200, val 20, pointer to 0x300
Node C：Address 0x300, val 30, pointer to NULL
```

|         | head                | new_head             | head->next->next = head     | head->next = NULL        |
| ------- | ------------------- | -------------------- | --------------------------- | ------------------------ |
| Loop1   | 0x200               | 0x300                | (0x200->next)->next = 0x200 | 0x200->next = NULL       |
| Loop2   | 0x100               | 0x300                | (0x100->next)->next = 0x100 | 0x100->next = NULL       |

### Solution 2
```c =
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* reverseList(struct ListNode* head) {
    if (head == NULL || head->next == NULL) {
        return head; 
    }

    struct ListNode* new_head = reverseList(head->next); // In the example above, it will enter the function twice.

    head->next->next = head; 
    head->next = NULL;       

    return new_head;
}
```
