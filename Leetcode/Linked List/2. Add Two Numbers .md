# 2. Add Two Numbers 

### Problem
You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.

You may assume the two numbers do not contain any leading zero, except the number 0 itself.

```
Example 1:
Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]
Explanation: 342 + 465 = 807
```
### Note
Why dummyHead exists ?  
When building a new linked list from scratch, there's a tricky special case: the very first node. Normally, adding a node means attaching it to the next of some existing node — but at the start, there is no existing node yet.
Why if (l1 != NULL) l1 = l1->next ?  
l1 and l2 are pointers walking through the two input lists, one node at a time. The two input numbers can have different lengths, so one list may run out before the other.
Once a list runs out, its pointer becomes NULL. Advancing a NULL pointer (NULL->next) is not allowed and would crash the program.
Why struct ListNode* result = dummyHead->next ?  
Remember, dummyHead itself was never a real digit — it was just scaffolding to make the first attachment easy. The actual answer starts one node later, at whatever dummyHead->next points to.
### Solution
```c
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     struct ListNode *next;
 * };
 */
struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    // Initial
    struct ListNode* dummyHead = malloc(sizeof(struct ListNode));
    dummyHead->val = 0;
    dummyHead->next = NULL;
    struct ListNode* curr = dummyHead;
    int carry = 0;

    while (l1 != NULL || l2 != NULL || carry != 0) {
        int x = (l1 != NULL) ? l1->val : 0;
        int y = (l2 != NULL) ? l2->val : 0;
        int sum = carry + x + y;
        carry = sum / 10;
        // Initial
        curr->next = malloc(sizeof(struct ListNode));
        curr->next->val = sum % 10;
        curr->next->next = NULL;
        curr = curr->next;
  
        if (l1 != NULL) l1 = l1->next;
        if (l2 != NULL) l2 = l2->next;
    }

    struct ListNode* result = dummyHead->next;
    free(dummyHead);  // Free the memory allocated for dummyHead
    return result;
}
```
