# 1047. Remove All Adjacent Duplicates In String

### Problem
You are given a string s consisting of lowercase English letters. A duplicate removal consists of choosing two adjacent and equal letters and removing them.

We repeatedly make duplicate removals on s until we no longer can.

Return the final string after all such duplicate removals have been made. It can be proven that the answer is unique.
```
Example 1:
Input: s = "abbaca"
Output: "ca"
Explanation: 
For example, in "abbaca" we could remove "bb" since the letters are adjacent and equal, and this is the only possible move.
The result of this move is that the string is "aaca", of which only "aa" is possible, so the final string is "ca".
```
### Note

Original Algorithm

1. Initiate an empty output stack. (We used the same memory in the solution)
2. Iterate over all characters in the string.
    - If the current element equal to the last element in the stack? Pop that last element out of the stack.
    - If the current element is not equal to the last element in the stack? Add the current element into the stack.
3. Convert stack into the string and return it.

### Solution
```c
char* removeDuplicates(char* s) {
    int new_len = 0;
    int len = strlen(s);

    for (int i = 0; i < len; i++) {
        if (new_len != 0 && s[new_len - 1] == s[i]) {
            new_len--;
        } else {
            s[new_len++] = s[i];
        }
    }

    s[new_len] = '\0';
    return s;
}
```
