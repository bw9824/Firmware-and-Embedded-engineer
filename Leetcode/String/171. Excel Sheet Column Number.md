# 171. Excel Sheet Column Number

### Problem
Given a string columnTitle that represents the column title as appears in an Excel sheet, return its corresponding column number.

For example:

A -> 1
B -> 2
C -> 3
...
Z -> 26
AA -> 27
AB -> 28 
...

```
Example 1:
Input: columnTitle = "ZY"
Output: 701
```

### Solution 1
```c =
int titleToNumber(char* columnTitle) {
    int ans=0;
    for (int i=0; i<strlen(columnTitle); i++){
        ans *= 26;
        ans += columnTitle[i]-64; //'A'=65
    }
    return ans;
}
```

### Solution 2
```c =
int titleToNumber(char* columnTitle) {
    long long ans = 0; // To prevent overflow of ans * 26 due to extremely large strings.
    
    // Instead of using strlen, stop at the end of the string, '\0'.
    for (int i = 0; columnTitle[i] != '\0'; i++) {
        ans *= 26;
        // More general and readable
        ans += (columnTitle[i] - 'A' + 1);
    }
    
    return (int)ans;
```
